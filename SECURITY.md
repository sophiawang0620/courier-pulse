# Security Policy

Please do not disclose vulnerabilities, credentials, real waybills, phone numbers, or full addresses in a public issue.

Report a vulnerability through GitHub's private vulnerability reporting feature when it is enabled for this repository. If that feature is unavailable, contact the repository owner privately and include only the minimum reproduction data required. Use synthetic waybills and redacted provider responses whenever possible.

The latest commit on `main` is the supported version during the v0.x period. Security fixes may be released without backporting to older commits.
